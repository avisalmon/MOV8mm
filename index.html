Enhancement Pipeline

Powerful AI Enhancement Features

🎯

Video Stabilization

Remove camera shake using OpenCV motion estimation. Smooth, steady footage from handheld projector scans.

✨

Deflickering

Eliminate brightness flickering from old projectors using temporal median filtering. Consistent, smooth playback.

🧹

Temporal Denoising

Advanced 7-frame Non-Local Means algorithm removes grain while preserving details. Cinema-quality clarity.

🚀

AI Upscaling

Real-ESRGAN neural network upscales to 2x or 4x resolution. Transform 480p footage to stunning 1080p or 4K.

👤

Face Restoration

GFPGAN v1.4 enhances facial details. See your loved ones' faces with incredible clarity and sharpness.

🔍

Detail Enhancement

Smart unsharp masking with edge detection. Brings out fine details without introducing artifacts.

Get Started in Minutes

1

Clone the Repository

git clone https://github.com/avisalmon/MOV8mm.git

Download the complete pipeline to your computer.

2

Install Dependencies

pip install -r requirements.txt

Requires Python 3.12+, CUDA 12.1+, and 8GB+ GPU VRAM.

3

Run Setup

python setup.py

Automatically downloads AI models and configures your environment.

4

Restore Your Films!

python scripts/enhance_video.py input.mp4 --upscale 2

Transform your precious memories with one command.

System Requirements

🖥️

Operating System

Windows 10/11, Linux, or macOS with Python 3.12+

🎮

GPU Required

NVIDIA GPU with 8GB+ VRAM (tested on RTX 4060). CUDA 12.1+ required.

⏱️

Processing Time

~1 hour for 10 seconds, ~6 hours for 60 seconds of footage (RTX 4060).
